# ktakeda-plugins

```
/plugin marketplace add KentarouTakeda/ktakeda-plugins
/plugin install ktakeda-skills@ktakeda-plugins
```

- `/ktakeda-skills:issue-determinacy`
  - 要件の解釈が一意に定まるか実測し、ブレた場合、最小限の修正量と文章量で修正することを支援。
- `/ktakeda-skills:refute-loop`
  - レビューループ。設計→実装、またはレビュー単体を、「多観点レビュー→反証→裁定→修正」により最小限の修正量とコード量で収束させる。
- `/ktakeda-skills:pending-review`
  - 主にAIによるPRを人間がレビューする際の支援。自分のPRに自分が付けたpendingコメントへ対応するツール。
